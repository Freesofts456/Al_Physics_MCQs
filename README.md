# A/L භෞතික විද්‍යා MCQ පුහුණුව

සිසුන්ට අන්තර්ජාලයෙන් A/L භෞතික විද්‍යා MCQ වලට පිළිතුරු දීමට හැකි සරල වෙබ් අඩවියකි. සේවාදායකයක් (server) අවශ්‍ය නැත.

## ගොනු
- `index.html` : ප්‍රධාන පිටුව
- `css/style.css` : පෙනුම
- `js/questions.js` : පාඩම් සහ ප්‍රශ්න (මෙහි ප්‍රශ්න එකතු කරන්න)
- `js/app.js` : ප්‍රශ්න පෙන්වීම සහ ලකුණු ගණනය

## ප්‍රශ්නයක් එකතු කරන ආකාරය
`js/questions.js` හි `Q` ලැයිස්තුවට මෙසේ එකතු කරන්න:

```js
{t:0, q:"ප්‍රශ්නය", o:["1","2","3","4","5"], a:2, e:"පැහැදිලි කිරීම"},
```
- `t` : පාඩමේ අංකය (`T` ලැයිස්තුවේ සුචිය, 0 සිට)
- `a` : නිවැරදි විකල්පයේ සුචිය (0 සිට; 0 = විකල්පය 1)

## GitHub Pages මඟින් පළ කිරීම
1. GitHub හි නව repository එකක් සාදන්න.
2. මෙම ගොනු සියල්ල upload කරන්න (`index.html` repository එකේ මුල් ස්ථානයේ තිබිය යුතුය).
3. **Settings > Pages > Source** හි `Deploy from a branch` තෝරා, branch එක `main` සහ folder එක `/ (root)` ලෙස තබා Save කරන්න.
4. මිනිත්තු කිහිපයකින් `https://<ඔබේ-නම>.github.io/<repository-නම>/` ලිපිනයෙන් අඩවිය ලබාගත හැක.

## විභාග ක්‍රමය (Exam mode)
ආරම්භක පිටුවේ "ක්‍රමය" කොටසින් **විභාග ක්‍රමය** තෝරන්න. කාල ගණකය (ප්‍රශ්නයකට විනාඩි 2.4), ප්‍රශ්න පුවරුව, සලකුණු කිරීම සහ පත්‍රය බාරදීම ඇතුළත් වේ. පිළිතුරු සහ පැහැදිලි කිරීම් පෙන්වන්නේ පත්‍රය බාරදුන් පසුවය.
ප්‍රශ්න 50ක් සඳහා `js/questions.js` හි ප්‍රශ්න එකතු කර, `js/app.js` හි `[5,10,20]` ලැයිස්තුවට `50` එක් කරන්න.
